# Learning DevOps

## DevOps Definition

DevOps is a culture and set of a practices that combines Development and Operations to deliver software faster, more reliably, and with automation.

Key words:

    - Collaboration
    - Automation
    - Continuous Improvement

---

## Continuous Integration (CI)

Continuous Integration (CI) is the practice of frequently merging code into a shared repository. Every code change triggers automated build and testing to detect issues early.

## Continuous Delivery (CD)

Continuous Delivery (CD) ensures that after a successful build and testing process, the application is ready for deployment. Before releasing to production, it requires manual approval.
