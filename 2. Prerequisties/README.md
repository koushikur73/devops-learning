# Prerequities and Setup

Steps :
    1. Install choco on windows.
    2. Install Virtual Box using Powershell as Admin
        ```bash
        choco install virtualbox -y
        ```
    3. Install vagrant using Powershell as Admin
        ```bash
        choco install vagrant -y
        ```
    4. Install JDK
        ```bash
        choco install openjdk -y
        ```
    5. Install Maven
        ```bash
        choco install maven -y
        ```
    6. Install AWSCLI
        ```bash
        choco install awscli -y
        ```
    
    Note : VS Code & Git are mandatory.
