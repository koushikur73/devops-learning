# Task 01 - Linux File Management

## Objective

Practice basic Linux file and directory management commands by creating a simple company directory structure.

## Directory Structure

```text
company/
├── HR/
│   ├── employees.txt
│   └── salary.txt
├── IT/
│   ├── developers.txt
│   └── servers.txt
├── Sales/
│   └── clients.txt
└── ZBackup/
```

## Commands Used

```bash
mkdir
touch
ls
tree
cat
```

## What I Did

- Created a company directory structure.
- Created department folders.
- Created employee, salary, developer, server, and client files.
- Verified the structure using the `tree` command.

## Output

The directory structure was created successfully.
