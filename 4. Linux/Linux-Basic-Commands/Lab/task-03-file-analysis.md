# Task 03 - File Analysis

## Objective

Practice Linux commands used for reading and analyzing file contents.

## Commands Used

```bash
head employees.txt

tail employees.txt

wc employees.txt
```

## Output

- Displayed the first lines of the file using `head`.
- Displayed the last lines using `tail`.
- Counted lines, words, and characters using `wc`.

## Command Explanation

### head

Displays the first 10 lines of a file by default.

### tail

Displays the last 10 lines of a file by default.

### wc

Counts:

- Lines
- Words
- Characters
