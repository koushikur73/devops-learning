# Task 04 - File Comparison and Sorting

## Objective

Practice comparing files and sorting text data.

## Commands Used

### Compare Files

```bash
diff employees.txt salary.txt
```

### Sort File

```bash
sort developers.txt
```

## Output

### diff

Compared two files line by line and displayed the differences.

### sort

Sorted the contents of `developers.txt` alphabetically.

- `screenshots/Difference.png`

## What I Learned

- `diff` helps compare files and identify differences.
- `sort` arranges text in alphabetical order.
- These commands are useful for configuration files, logs, and reports.
