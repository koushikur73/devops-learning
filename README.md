# Learning DevOps

## DevOps Definition

DevOps is a culture and set of a practices that combines Development and Operations to deliver software faster, more reliably, and with automation.

Key words:

    - Collaboration
    - Automation
    - Continuous Improvement


## Continuous Integration (CI)

CI is the practice of frequently merging code into a shared repository and running automated tests.

## Continuous Delivery (CD)

After build the CI and pass the test, Ready for Deployment and it needs to Manual Approval and then go to Production. This is the whole process of CD.
