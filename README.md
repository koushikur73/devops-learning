# Learning DevOps

## DevOps Definition

DevOps is a culture and set of a practice that combines Devepoment and Operations to deliver software faster, more realibly, and with automation.

Key words:

    - Collaboration
    - Automation
    - Continuous Improvement


## Continuous Integration (CI)

CI is about repeatedly Merging code and runnig automated tests.

## Continuous Delivery (CD)

After build the CI and pass the test, Ready for Deployment and it needs to Manual Approval and then go to Production. This is the whole process of CD.
